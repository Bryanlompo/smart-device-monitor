# Smart Device Monitoring System

A computer engineering learning project developed step by step, starting with a C++ simulator and later using an ESP32-S3.

## Purpose
Build a monitoring system that acquires measurements, detects abnormal conditions, and reports information. The project will provide practice in embedded C++, modular design, debugging, hardware interfaces, testing, and documentation.

## Development approach
All implementation code will be written progressively by the student, with review and guidance at each step. **No implementation code has been provided in this repository.**

## Current status
**Planning stage — no source code or automated tests yet.**

## Upcoming milestones
1. Understand the requirements and design the first program.
2. Create the desktop C++ simulator from scratch.
3. Test and improve the simulator.
4. Develop firmware when ESP32-S3 hardware is available.
5. Integrate sensors, document validation, and prepare the final demonstration.
